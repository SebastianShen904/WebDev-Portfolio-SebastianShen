# Portfolio Website

## Purpose
This repository houses my personal portfolio website, designed to showcase my journey in software development, engineering projects, and technical skills. It serves as a central hub for my academic achievements and highlights my experience with various programming languages and community initiatives.

## Features
* **Responsive Design:** Fully accessible on mobile, tablet, and desktop.
* **Project Gallery:** Interactive cards highlighting my work in C++, physics simulations, and open-source contributions.
* **Contact Integration:** Direct links to my professional social media and GitHub repositories.

## Tech Stack
* **HTML5:** Semantic structure for accessibility.
* **CSS3:** Custom layouts using Flexbox and Grid.
* **JavaScript:** Dynamic content rendering and UI interactions.
